#Digital Board - Frontend MVP
Overview

This is a frontend-only project for a digital board where users can add, edit, and position text-based pins anywhere on the blank canvas.

I want to explicitly state that not all the advanced requirements in this original task document have been implemented. As I am at a early stage in my development journey, I have prioritized the delivery of a clean, functioning, structured core solution over attempting features that could not yet be justified or maintained.

This submission is to show genuine effort, earnest learning, and a foundation, fully developed from scratch.

##Reason for taking this task:

Being a beginner in the industry, my main goals were to:

- Understand how real interactive web applications work
- Translating ideas into functional code
Solution. Avoid depending on copied solutions without understanding.

- Create something simple, useful and extensible Every aspect of this project has been developed with clarity in mind both for myself and any reviewer of the code.

##Implemented Features
Blank Canvas Interface
- A full-screen canvas that initializes empty.

- Pins can be freely put anywhere on the board.
Text Pins
- Multiple text-based pins can be created.

Text in every pin is editable.
- Text can be updated directly by clicking and typing.
Drag & Drop Interaction

-Pins can be dragged and moved anywhere freely.
- Movement is smooth and intuitive through mouse input.
• There is a clear distinction between dragging and text editing to ensure better user experience.

Persistent State (Local Storage)
- All pins, including contents and position, are saved automatically.
REST: Pins are restored exactly as they were after a page reload.
The app implements persistence through the browser’s localStorage in an elegant way.

Clean & Beginner-Friendly Code Base
- Implemented using only HTML, CSS, and Vanilla JavaScript.
- No external libraries or frameworks are used.
- Clear variable names and readable logic.
- Structured to support future extension

Technical Highlights Frontend only implementation. Frameworks and build tools are not needed. - Event-driven interaction using mouse events. Input State is stored as structured JavaScript objects. - Client-side persistence is per-user / per-browser. This project runs by simply opening index.html in a browser.
